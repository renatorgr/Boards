AiO v4.5 web page simulator

Try the web pages of the AiO v4.5 autosteer module without a module. These are the real pages from the firmware, rebuilt from the code on every change. The values behind them are made up: a tractor drives up and down a field with autosteer on.

Teensy module page

What the module shows at http://192.168.5.126/ on the tractor's network: GNSS, IMU, steering, messages, settings, the GPS receiver, the machine module and the firmware update.

XIAO Wi-Fi page

What the XIAO ESP32 on the GPS2 port shows on its own Wi-Fi network, at http://192.168.4.1/, made for a phone. Its password here is agopengps.

Open

Some set-ups to start from

  • UM982 with two antennas, TM171, Cytron valve, AgOpenWeb
  • F9P, BNO085, Keya motor, AgOpenGPS
  • Dual F9P, BNO085 in RVC mode, IBT2 motor, AgOpenGPS
  • X20P and TM171, no XIAO, no machine module, tractor parked
  • UM982 and TM171 with the official AgOpenGPS machine module (Machine_UDP_v5)

Change the receiver, the IMU, the steering, the program, the XIAO and the machine module in the strip at the top of each page. With the tractor parked you can try what the module refuses while autosteer is on: the firmware update, the TM171 calibrations, writing the receiver settings.
