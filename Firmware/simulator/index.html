AiO v4.5 web page simulator

Try the web pages of the AiO v4.5 autosteer module, its XIAO and the ESP32 seed drill and sprayer modules without a board. These are the real pages from the firmware, rebuilt from the code on every change. The values behind them are made up: a tractor drives up and down a field with autosteer on, sowing with a 19-section no-till seed drill (or spraying, when the sprayer is chosen in the strip).

Teensy module page

What the module shows at http://192.168.5.126/ on the tractor's network: GNSS, IMU, steering, messages, settings, the GPS receiver, the machine module (every section, with a link to the module's own page) and the firmware update.

Seed drill module page

What the seed drill's KinCony KC868-A32 (Seeder_ESP32) shows on its own Wi-Fi network (Seeder-xxxx, at http://192.168.4.1/) or on the tractor network at http://192.168.5.123/: the 19 sections asked for and open, the 32 relays, the network cable, the settings and the program update. Its password here is agopengps.

Sprayer module page

What the ESP32 sprayer module (Sprayer_ESP32 on the ESP32_Relay_X8 board) shows on its own Wi-Fi network (Sprayer-xxxx, at http://192.168.4.1/) or on the tractor network at http://192.168.5.123/: pressure, flow and litres, the sections asked for and open, the relays, the Wi-Fi settings, the calibration and the program update. Its password here is agopengps.

Some set-ups to start from

  • UM982 with two antennas, TM171, Cytron valve, AgOpenWeb
  • F9P, BNO085, Keya motor, AgOpenGPS
  • Dual F9P, BNO085 in RVC mode, IBT2 motor, AgOpenGPS
  • X20P and TM171, no XIAO, no machine module, tractor parked
  • UM982 and TM171 with the official AgOpenGPS machine module (Machine_UDP_v5)
  • UM982 and TM171 with the 8 m sprayer: 5 sections, pressure, flow and litres on the Machine tab
  • Sprayer module page with the 8 m sprayer on the ESP32_Relay_X8 board: 8 relays, the boom's readings
  • Seed drill module with the network cable unplugged: rows closed, the program's request outlined

Change the receiver, the IMU, the steering, the program, the XIAO, the machine module and the implement (the no-till seed drill with 19 sections, or the 8 m sprayer with 5 sections) in the strip at the top of each page. With the tractor parked you can try what the module refuses while autosteer is on: the firmware update, the TM171 calibrations, writing the receiver settings.
