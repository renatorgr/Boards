AiO v4.5 web page simulator

The real web pages of the AiO v4.5 module, its XIAO and the seed drill and sprayer modules, with a pretend tractor behind them: it drives up and down a field with autosteer on, sowing with the 19-section seed drill. No board needed. Rebuilt from the firmware on every change.

Set up AgOpenWeb from your measures

Type the tractor and implement measures and get AgOpenWeb's U-turn, headland and tramline settings, with the reasons.

The password on the module pages is agopengps. The strip at the top of each page changes the receiver, the IMU, the steering, the program, the implement or the network, and parks the tractor to try what the module refuses while autosteer is on.

Some set-ups to start from

  • UM982 with two antennas, TM171, Cytron valve, AgOpenWeb
  • F9P, BNO085, Keya motor, AgOpenGPS
  • Dual F9P, BNO085 in RVC mode, IBT2 motor, AgOpenGPS
  • X20P and TM171, no XIAO, no machine module, tractor parked
  • The official AgOpenGPS machine module (Machine_UDP_v5)
  • The 8 m sprayer on the Machine tab
  • Seed drill module with the network cable unplugged
